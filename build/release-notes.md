# 每日记事本 1.6.0 更新说明

## 🗑️ 回收站

- 删除的任务不再直接消失，而是先进入回收站，随时可以恢复
- 支持单条恢复、勾选多条批量恢复、一键全部恢复
- 支持单条彻底删除、批量彻底删除所选、一键清空回收站
- 回收站内支持按标题 / 备注搜索
- 恢复与彻底删除均有趣味确认弹窗（"哼哼，现在知道挽留我了 😤" / "你真的一点都不挽留我了吗？ 😭"）
- 桌面端侧边栏与手机端底部导航新增回收站入口（带数量角标），快捷键 `6` 直达

## 📌 快速输入框置顶

- 今天、重要事项、时间甘特图、即将到来、记事五个页面的快速输入框统一移到页面最顶部（汇总卡片上方），录入更顺手

## 🖥️ 系统托盘

- 点击窗口 X 时可选择「最小化到托盘」或「彻底退出」
- 最小化到托盘后窗口不再占用任务栏（Linux 任务栏 / macOS 程序坞 / Windows 任务栏），仅保留系统托盘/状态栏图标
- 托盘图标菜单：显示主界面 / 彻底退出；Windows 下左键单击托盘图标直接恢复窗口
- macOS 隐藏到托盘时同步隐藏 Dock 图标，恢复窗口时自动还原
- 新增单实例锁：应用已在运行时再次点击启动器，会唤起已有窗口而不是打开新进程

## ❌ 关闭行为可记忆

- 关闭询问弹窗新增「以后不再显示此询问」勾选框，记住你的选择，之后点 X 直接执行对应操作
- 设置 → 通知 栏目新增「关闭窗口前询问」开关，可随时重新开启询问或改回直接执行

## ⬇️ 应用内更新提示

- 发布新版本后，应用左下角会出现「发现新版本，点击下载」徽标，点击直达 GitHub Release 页面
- 支持同版本号重新发布的提醒；提示可一键关闭，也可稍后再说
- 菜单栏「应用 → 检查更新…」可手动触发检查
